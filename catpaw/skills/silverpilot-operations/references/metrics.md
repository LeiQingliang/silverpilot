# 指标释义

运行成功率 = (COMPLETED + WAITING_CONFIRMATION) / 全部运行。它用于描述 Agent 运行结果，不等于预约成功率或满意度。DEGRADED 是独立状态。

业务动作结果按 SUCCEEDED、CANCELLED、EXPIRED、FAILED、EXECUTING、PENDING 分别展示；只有 SUCCEEDED 表示后端办理成功。遇到未知状态（例如外部文件中的 EXECUTED）保留原值并要求核对导出版本，不自行映射为成功。一个任务可能发生多次运行，动作也可能在创建之后执行；没有可靠关联和统一观察窗口时，不能用动作数除运行数构造转化率，也不能归因到模型。

反馈关闭率按导出中的 definition 使用创建时间 cohort，VERIFIED 才计入分子；观察窗口未成熟时可能低估最终关闭率。零分母显示“暂无数据”，不显示 0%。

P50/P95 使用有序有效延迟的 nearest-rank 分位数。空运行样本的 API 可能返回 0，应表述为“暂无数据”，不能解释为零耗时或零成功率。少量样本的 P95 不代表长期 SLA。导出存在 truncated 时，仅描述所选样本，不称为完整周期。

人工与 AI 辅助耗时对照必须使用同一任务和交付质量标准，记录样本量、实际耗时、返工和核验时间。没有对照记录不声称效率提升。

报告注明来源是：真实授权使用、合成演示、mock 或未知。平台运行数据本身无法证明用户是真实养老机构客户。
