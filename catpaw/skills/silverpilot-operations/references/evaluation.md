# 可复现模型比较

使用仓库 scripts/run-agent-evaluation.ps1 的 schemaVersion=2 报告。先固定代码、知识、Prompt、数据集、用例、试验次数和环境，再分别运行模型。

脚本记录本地源码提交、是否未提交、知识/Prompt/数据集 SHA256、服务端 Prompt 快照、实际模型、run ID、延迟、Token 和错误原因。本地指纹不能证明远端运行了相同代码；必须确认被测栈来自同一构建。不同模型默认采样参数可能不同，应在实验记录中列出。

运行：

    python scripts/analyze_evaluations.py report-a.json report-b.json --output comparison.md

本脚本位于技能目录内。一个报告可单独汇总；两个报告仅在证据类型、提交、指纹、用例及试验数一致且源码干净时允许对比。synthetic/mock 可以验证分析流程，但不能推断真实模型效果。保留所有试验，不挑选最好的一次；延迟统计注明只覆盖有运行记录的请求。

契约、安全阻断与人工质量评分分别报告。人工评分至少检查事实依据、必要条件澄清、工具选择、下一步可理解性；输出已知事实和“待评分”，不能由模型自己打分替代独立复核。
