# 用途

这一目录同时是 SilverPilot 后端的受控检索源和 ima 导入包。只有 `status: approved` 且审核日期有效的 Markdown 会被运行时 Agent 检索：按 Asia/Shanghai 日期满足 `reviewed_at ≤ 今天 ≤ next_review_at`。缺失、非法、重复或前后矛盾的审核日期不能进入检索；缓存命中也重新检查到期日。

2026-11-06 更新的是上述工程执行规则，不代表重新进行知识内容专业复核；原审核日期保留。

# 入库门槛

1. 一文一主题，先写适用范围，再写流程和边界。
2. 必须填写文档 ID、负责人、版本、审核日期和下次审核日期。
3. 医疗健康内容只能做科普和风险分流，不能开诊断、药方或用药调整。
4. 业务数字必须有可核验口径；模拟 ROI、客户和销售话术必须显式标注为演示。
5. 禁止写入 API Key、口令、Token、真实身份证号、病历和联系方式。
6. 重复、过期、无来源或彼此冲突的内容不得进入 `approved`。

# ima 导入

- 在 ima 中新建专用知识库，名称建议为“SilverPilot 智慧养老业务知识库”。
- 只导入本目录中 `approved` 且在审核有效期内的 Markdown 文档，不导入 `draft`、治理规范、数据库备份、日志、密钥文件和生成产物。
- 在 WorkBuddy 绑定 ima 资料库后，使用 `@资料库名称` 进行检索，回答应保留 `document_id`。
- 更新时先运行 `scripts/validate-knowledge-base.ps1`，然后整包替换，避免新旧版本并存。

# 下线规则

文档过期、业务规则变更或来源失效时，将 `status` 改为 `draft` 并先从 ima 移除；复核通过后再升级版本。

已隔离 `draft` 可以保留原过期日期作为待办证据，结构校验会报告警告；这不代表完成复核。`approved` 和 `governance` 过期仍阻断门禁。所有状态均要求完整、合法的日期与前后关系，`reviewed_at` 不得写成未来日期。不得通过修改审核时间来掩盖未完成的复核。
