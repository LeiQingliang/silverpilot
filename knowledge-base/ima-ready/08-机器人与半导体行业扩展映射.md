# 适用范围

本蓝图用于讨论机器人设备和半导体元器件的售前需求。SilverPilot 当前工具处理社区养老业务。下表右栏均为行业方案设想，实施前需要取得产品资料、业务系统接口和审批授权。

# 从现有工程到拟建流程

| SilverPilot 已有依据 | 行业方案设想与接入前提 |
| --- | --- |
| `list_services` 从养老服务目录获取候选项目。 | 机器人选型可先按应用场景、负载和工作范围筛选型号；元器件选型可先按料号、封装和接口筛选候选件。须接入有授权、含单位和生效版本的产品主数据，缺项交产品工程师核对。 |
| 养老预约写操作先生成待确认动作，后端校验确认用户、有效期和状态，再执行并留痕。 | 可为样机申请或报价设计相似流程。须另行定义客户归属、可申请的样机、报价有效期、折扣审批人及目标系统回执。居民确认逻辑只能作为设计参考。 |
| 知识检索筛选已审核且有效的 Markdown，返回来源标识。 | 可为规格书建立厂商、料号、文档修订号和适用型号记录。候选件的参数必须能追溯至当期原始规格书；来源冲突或版本缺失时交人工核对。 |
| 运行记录按时间窗口统计调用次数、成功率和平均耗时。 | 若需统计样机转化或报价转单，须先从商机系统采集阶段进入时间、分母、回执与结束状态，并区分测试记录与实际商机。 |

# 怎样验证行业原型

从一个型号系列和一个只读问题开始。例如，选两份经授权、修订号不同的规格书，让原型返回候选型号、引用版本及待补字段。由产品工程师用规格原文核对结果；没有有效来源时，验收应看到明确的缺项说明。样机申请、商务报价、设备遥测和维保工单各自需要业务接口、权限和异常处理，须另行立项验证。
