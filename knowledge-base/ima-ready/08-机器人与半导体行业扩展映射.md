# 可复用能力

- 产品目录检索：养老服务目录可映射为机器人机型、配件、芯片或解决方案选型。
- 需求参数化：服务日期和地址可映射为场景、节拍、负载、算力、接口、交付周期和预算。
- 人在回路：业务确认可映射为报价、样机申请、方案发送和交付节点审批。
- 知识治理：同一个受控知识包机制可管理数据手册、规格、FAQ、竞品对比和行业方案。
- 运营观测：任务成功率、工具成功率和失败分布可扩展为线索转阶、方案命中、样机转化和交付风险。

# 需新增的真实数据契约

以下是路线图，当前项目不声称已具备：

1. 产品规格、版本、库存、交期和区域准入的主数据。
2. 客户线索、商机阶段、决策链、客户互动和授权同意字段。
3. 报价版本、折扣审批、合同、验收和回款状态机。
4. 硬件遥测、告警、维保工单和售后 SLA，以及相应的设备身份与权限。
5. 芯片样品和数据手册的版本关联，避免 Agent 把旧规格用于新型号。

# 可用于面试的真实表述

可以说“我实现了一个带工具调用、人工确认、权限校验、知识治理和运营指标的养老 Agent，并设计了它向机器人/半导体解决方案销售迁移时需要的数据契约”。不可以说“已为机器人或芯片客户部署”。
