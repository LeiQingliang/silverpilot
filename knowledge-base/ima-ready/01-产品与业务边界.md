# 产品定位

SilverPilot 是面向社区居民和运营人员的养老服务演示原型。居民在「小伴生活助理」中查目录、看自己的记录和提出办理请求。后端按登录身份访问业务数据，运营人员可查看运行状态和问题复测记录。

# 居民能办理哪些事

| 场景 | 可查询的内容 | 有写权限的账号可确认办理 |
| --- | --- | --- |
| 活动 | 当前可报名活动 | 报名参加一项活动 |
| 上门服务 | 可预约的服务、本人服务订单 | 预约服务或取消本人待受理订单 |
| 助餐 | 菜谱、本人助餐订单 | 预订菜谱或取消本人待处理预订 |
| 健康记录 | 本人体检报告列表及指定报告的指标 | 只读 |

小伴还可以按词项检索处于复核有效期内的已批准知识文件，并在命中时返回形如 `[KB:文件名]` 的来源标记。照护建议功能结合服务目录和允许引用的证据，帮助用户选择可咨询的服务。诊断、处方和用药决定由医疗专业人员处理。

# 怎样判断是否办成

公网演示站的共享账号按只读权限体验查询。要验证预约，使用有写权限的本地测试账号与虚构信息。核对确认卡的服务、日期和地址摘要，此时 `PENDING` 仅表示待确认。点击「确认并执行」后，查看后端返回结果并在「服务订单」核对本次订单。若选择「暂不执行」，本次待确认预约应被取消。

仓库展示的是可运行的产品功能。机构试点、用户任务完成率、付费意愿和业务收益各需独立的试点或研究记录。外部助手的客户端连接也须单独验证。
