# 产品定位

SilverPilot 是面向老年用户与养老业务运营人员的执行型 AI Agent 平台。它将自然语言需求转成可追踪工具调用，并在写入业务数据前要求人工确认。

# 已落地能力

- 查询可报名活动，并在确认后报名。
- 查询养老服务和个人订单，并在确认后预约或取消。
- 查看当前账号的健康报告，不做诊断。
- 检索菜谱、查看助餐订单，并在确认后预订或取消。
- 检索本地已审核知识库，返回可追溯的 `[KB:...]` 来源。
- 记录模型、输入模态、延迟、工具调用和失败类型，不保存原始对话。

# 不做什么

- 不自动扣款，不跳过用户确认，不操作其他用户数据。
- 不冒充医生，不对健康图片给出确定诊断。
- 不声称已与医院、政府、社区或商业客户上线，除非有真实验收证据。
- 不把 WorkBuddy/ima 的手动绑定描述成未经验证的 API 实时同步。

# 成功标准

任务是否成功由真实业务工具结果、安全护栏和运行记录共同判定，不以模型语气或页面动效代替验证。
