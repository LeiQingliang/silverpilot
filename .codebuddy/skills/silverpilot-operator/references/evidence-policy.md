# Portfolio evidence policy

Defensible claims must point to code, tests, a reproducible command, a database record, or a live smoke result. This project can evidence Agent orchestration, tool calling, confirmation, permissions, audit, multi-provider routing, image-input plumbing, knowledge governance, MCP, metrics, tests, and product/sales-demo design.

Do not claim real customers, contracts, revenue, conversion, retention, production deployment, medical accuracy, Doubao availability, WorkBuddy binding, or ima synchronization without current external evidence. Label demos, mock discovery calls, ROI models, robot/semiconductor mappings, and roadmap functions as simulations or designs.

For AI operations roles, emphasize evaluation, KPI definitions, failure analysis, prompt/model boundaries, knowledge quality, and cross-functional release gates. For AI sales or solutions roles, emphasize discovery, technical-to-business translation, demo design, security objections, acceptance criteria, and delivery handoff.
