# SilverPilot 前端设计系统与验收基线

本规范对应 `SourceCode/cecsmsui-vue` 的当前可运行版本。设计借鉴 Apple 官网的产品叙事方法：克制的中性色画布、明确的大标题层级、充足留白、单一蓝色主操作和以真实内容为中心的模块化编排。项目不复制 Apple 的源码、商标、图片、视频或产品文案，所有业务内容与素材均来自 SilverPilot。

## 1. 第一性原则

1. **先完成任务，再表达品牌**：用户首先要看懂活动、服务、报告和操作后果；装饰不得压过信息。
2. **一个页面只保留一个视觉主角**：首页突出小伴，目录页突出当前服务，表单页突出当前动作，后台突出业务数据。
3. **层级依靠排版和空间**：大标题、短说明、留白和内容分组承担主要层级，不依赖霓虹、密集描边或无意义渐变。
4. **动作必须可预测**：主操作统一为蓝色；成功、警告、危险色仅表达状态和后果。提交、取消、删除和 Agent 写操作均给出明确反馈或确认。
5. **每种设备都能办事**：桌面、平板和手机共享业务能力；小屏把宽表格转换为卡片，不隐藏关键操作。
6. **媒体是内容，不是背景噪声**：图片必须有替代文本和失败回退；文件下载必须验证响应；视频必须有可见控制、错误态和可访问名称。

## 2. 视觉 Token

全局事实源为 `src/assets/main.css`。组件应复用语义变量，避免添加孤立的颜色、阴影和圆角。

| 类别 | 主要 Token | 约束 |
| --- | --- | --- |
| 画布 | `--sp-bg: #f5f5f7`、`--sp-surface: #fff` | 页面使用浅灰画布，内容使用白色表面 |
| 文本 | `--sp-text: #1d1d1f`、`--sp-text-secondary: #424245`、`--sp-text-muted: #6e6e73` | 标题、正文、辅助信息形成稳定三级层级 |
| 主操作 | `--sp-brand: #0066cc`、`--sp-brand-strong: #004f9e`、`--sp-brand-soft: #e8f2ff` | 链接、主按钮、选中态和键盘焦点 |
| 语义状态 | `--sp-success`、`--sp-warning`、`--sp-danger` | 只表达状态，不用作普通主操作 |
| 形状 | `--sp-radius-*`、`--sp-radius-pill` | 容器圆角大于控件圆角，胶囊只用于短标签和按钮 |
| 层级 | `--sp-shadow-*`、`--sp-border` | 默认以细边框分组，只在浮层和重点卡片使用阴影 |
| 动效 | `--sp-duration-*`、`--sp-ease-*` | 只动画 `opacity`、`transform` 等低干扰属性 |

字体使用 Apple 系统字体优先的跨平台系统栈，在 Windows 上自然回退到 Segoe UI 和中文系统字体。全站固定一套可访问浅色主题，避免双主题状态漂移和首屏闪烁。

## 3. 页面家族

`App.vue` 根据路由写入页面家族；当前 34 条受支持路由共用导航、表单、反馈、断点和媒体契约。

| 家族 | 页面范围 | 布局约定 |
| --- | --- | --- |
| `auth` | 登录、注册 | 产品说明与业务插画 + 单一表单任务区 |
| `public` | 首页、活动、服务、菜谱、社区 | 大标题产品舞台 + 模块化业务卡片 |
| `account` | 个人资料、活动、订单、评论、报告 | 清晰账户导航 + 可操作记录卡片 |
| `assistant` | 小伴入口、对话工作台 | 助手身份、快捷任务、对话区、能力与办理状态 |
| `admin` | 总览、Agent 运营和业务管理 | 低干扰侧栏、面包屑、标准工具栏、桌面表格/移动卡片 |

首页的产品舞台由大标题、两级操作、小伴设备框和三项服务承诺构成；不使用远程热链素材。后台和账户区不另造视觉体系，只提高信息密度。

## 4. 组件与交互状态

- 主按钮使用品牌蓝；普通次操作使用白底描边；绿色只表示在线、完成或健康状态；红色只表示危险操作。
- 输入、按钮和图标按钮均覆盖默认、悬停、按下、禁用、加载和 `focus-visible` 状态。
- 导航选中态同时使用色彩、背景或标记，不只依赖颜色差异。
- 加载、空数据、失败图片、API 错误和无权限都有可读反馈；加载遮罩不能无限停留。
- Agent 写操作必须先呈现对象、时间、费用或影响，再由用户确认；模型回复不能冒充已完成的业务写入。
- 移动端触控目标不小于 44px；页面不得产生文档级横向滚动。
- `prefers-reduced-motion` 关闭非必要动画；路由变化会重置焦点并提供跳到主要内容入口。

## 5. 媒体与文件契约

- `SmartImage.vue` 负责业务图片的加载、替代文本、WebP 优先、原图回退和失败占位。
- `optimizedImageUrl.js` 只为可转换的项目内图片生成 WebP 候选；SVG、外部地址和未知格式保持原路径。
- `scripts/optimize-images.ps1` 为运行时图片生成同名 WebP，不覆盖原文件；当前 101 组原图/WebP 可互相回退。
- `src/utils/download.js` 统一处理文件名、空响应、JSON 错误响应、Blob 下载、临时链接回收和 Object URL 释放。
- 视频区必须使用用户主动触发、明确停止和错误反馈。当前仓库没有持久化视频文件；小伴相机预览是唯一视频元素，并保留权限与设备失败提示。
- 不允许把第三方网页、CDN 或临时开发服务器作为正式图片、视频或文件依赖。

## 6. 响应式基线

| 基线 | 宽度 | 主要行为 |
| --- | --- | --- |
| Desktop | 1440×1000 | 完整导航、双列产品舞台、后台侧栏和数据表格 |
| Tablet | 768×1024 | 单列内容、折叠菜单、压缩标题和可换行工具栏 |
| Mobile | 390×844 | 图标导航、单列任务流、记录卡片、44px 触控目标 |

CSS 可以增加内容驱动断点，但不得让同一业务在三个验收基线上失去入口或关键操作。

## 7. 当前验收证据

2026-08-20 本机时间点基线：

- 前端单元测试 `37/37`，ESLint、Knip 和 Vite 生产构建通过；
- Edge 覆盖 34 条路由 × Desktop/Tablet/Mobile，共 `102/102` 场景通过；
- 每个浏览器场景检查空白页、重定向、Vue/控制台异常、资源 HTTP 错误、横向溢出、控件重叠、图片解码、可见音视频和卡死加载层；
- 同源前后端通信 `98/98`，覆盖验证码图片、Excel 导出、业务资源代理、上传读回与精确清理、Agent 状态和 MCP 只读目录；
- 真实 DeepSeek Agent 冒烟通过版本化 Prompt、知识库工具、结构化照护方案、MCP、待确认写操作与取消链路；取消前后服务订单 ID 快照一致；
- 媒体实体解码检查通过：207 个栅格图片、9 个 SVG、27 个 PDF/DOCX；持久化视频文件为 0；
- 人工截图抽查覆盖首页、登录、注册、小伴工作台、后台总览和移动管理卡片。

这些结果证明当前锁定依赖、演示数据与本机 Edge 的可运行状态，不等于 Safari、Firefox、真实读屏器、生产流量或全部终端均已认证。上线前仍需在目标设备复核关键办理路径。
