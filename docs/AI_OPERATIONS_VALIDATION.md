## 审查后修复

- LongCat 非法密钥字符可能进入 HTTP 构造错误：改为固定脱敏配置错误，并验证零网络请求和无密钥输出。
- MCP 指标响应原先包含 recentRuns 的用户信息：改为显式聚合白名单并增加隐私回归。
- 降级被算作运行成功：采用明确状态集合，未知状态也不计成功。
- 知识审核过期仍可运行时检索：按上海日期过滤，缓存跨日重新判定，草稿不参与检索。
- 失败工具可能通过评测、自动 Mock 可能标记成 live：核验轨迹状态和实际 Provider，分析器再次校验标签。
- 反馈界面不能区分相似问题：显示关联运行、创建时间及处理对象；审计写失败的事务回滚经代理测试。
- 前端已知漏洞：复用兼容修复并更新传递依赖；minimatch 11.0.1 覆盖经 lint、测试和构建验证。
