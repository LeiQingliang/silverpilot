## 影响与边界

- 普通启动不覆盖已有数据库卷。种子将 187 个非空日期固定到 2027 年，包含演示账户出生日期，并保留活动的固定快照日期；这些是演示值，不能用于真实年龄或业务时效判断。已有数据的迁移需单独执行。
- 启动窗口关闭、回车或浏览器打开失败后，服务继续运行；停止服务使用停止入口。清理默认保留活动服务，显式 `--stop-running` 才请求停止并清理。
- 活动编辑保存失败保留草稿，成功后刷新当前筛选；新增活动禁止过去日期，编辑允许修正历史日期。留言统一按北京时间显示，未来时间明确标识，同一时间以 ID 确定顺序。
- 启动与清理的边界情况由隔离回归覆盖。本次没有重新运行人工 IDEA/VSCode 模式切换或真实 AI 提供商调用，也没有将页面截图当作完整的交互验收。
- GitHub CI 的结论以对应 PR 的检查记录为准。本次由 Codex 复核已有本地代码、执行验证、补充界面证据并整理提交，包含 AI 辅助代码和测试，供维护者评审。
