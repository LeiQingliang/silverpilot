# SilverPilot v1.0.1

SilverPilot `v1.0.1` 是兼容 `v1.0.0` 的维护与供应链加固版本。本次没有数据库迁移、API 破坏性变化或生产部署声明；重点是让不可信输入边界、构建工具来源和 GitHub 发布治理更可验证。

> 这是个人工程作品和方案验证的稳定版本号，不代表养老机构生产认证、医疗器械资质、临床有效性、等保认证或长期 SLA。

## Highlights

- 5 组基于 `fast-check` 的属性测试以固定种子生成 10,000 个用例，覆盖聊天历史、AI 照护方案、统计数据、图片上传和媒体 URL。
- AI 统计与照护方案归一化拒绝 `NaN`/无穷值，并限制模型元数据、推荐理由与证据文本，避免异常响应扩散到界面状态。
- npm 12.0.2 在 Docker、CI 和 Release 中都从官方 tarball 安装并核对 SHA-256；基础镜像继续固定到 OCI 摘要。
- 最新 Docker Scout 数据首次复扫在 MySQL 上游快照中发现 4 个 High；派生镜像定向升级 Oracle `curl`/`libcurl` 修复包后，四个最终镜像均为 0 Critical/High。
- Release 契约要求全部远程 Action 使用 40 位提交 SHA，所有 checkout 步骤禁用凭据持久化。
- 仓库 Actions 允许列表仅接受 GitHub 官方 Action 与精确审核的 Scorecard/Gitleaks SHA；`v*` 标签禁止更新或删除，Release 继续保持不可变。

## Compatibility and migration

- 数据库 schema、Compose 卷、HTTP API 与配置键均未改变。
- 从 `v1.0.0` 升级无需数据迁移；使用源码构建时执行 `npm ci` 以安装新增的开发期属性测试依赖。
- 生产运行资产不包含 `fast-check`；它只参与开发与发布门禁。

## Release assets

| 资产 | 用途 |
| --- | --- |
| `silverpilot-1.0.1-source.zip` | 与 Release 提交完全对应的完整 Git 源码；推荐用于 Docker 快速评审 |
| `silverpilot-1.0.1-backend.jar` | Java 25 可执行 Spring Boot JAR；仍需外置 MySQL、Redis 与安全配置 |
| `silverpilot-1.0.1-frontend.zip` | 已构建的静态前端；需由支持同源 `/api` 代理的 Web 服务器托管 |
| `silverpilot-1.0.1.spdx.json` | GitHub Dependency Graph 导出的 SPDX 2.3 仓库 SBOM |
| `silverpilot-1.0.1-release-manifest.json` | 版本、标签、仓库、提交与资产角色清单 |
| `SHA256SUMS` | 所有自定义 Release 资产的 SHA-256 校验值 |

GitHub 还会提供自动生成的源码 `.zip` / `.tar.gz`。自定义源码包额外进入校验文件与构建来源证明，便于独立复核。

## Verify before use

```powershell
gh release verify v1.0.1 --repo LeiQingliang/silverpilot
gh release download v1.0.1 --repo LeiQingliang/silverpilot --dir .\silverpilot-v1.0.1
gh attestation verify .\silverpilot-v1.0.1\silverpilot-1.0.1-backend.jar `
  --repo LeiQingliang/silverpilot `
  --signer-workflow LeiQingliang/silverpilot/.github/workflows/release.yml
```

再按 `SHA256SUMS` 独立计算每个下载文件的 SHA-256，并确认 Release、标签、`main` 与发布清单中的提交 SHA 完全一致。

## Known boundaries

- 演示账号、示例密码和合成种子数据不得直接用于公网生产。
- OWASP Java Dependency-Check 的 NVD 数据更新曾超时，因此没有宣称该扫描通过。
- 属性测试是自动生成输入的工程门禁，不是形式化证明，也不覆盖浏览器内存、网络和后端所有状态组合。
- 未完成真实养老机构、临床、并发容量、灾备、Firefox/Safari、读屏器及独立渗透测试。
- WorkBuddy 企业发布、ima 账号绑定和豆包真实视觉能力仍需要相应外部账号与授权。
