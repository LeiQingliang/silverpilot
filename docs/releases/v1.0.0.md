# SilverPilot v1.0.0

SilverPilot `v1.0.0` 是首个正式、可验证的开源工程版本。它将智慧养老业务、可审计 AI Agent、人工确认写操作、Spring Boot 后端与 Vue 前端整理为可本地复现的单仓库基线。

> 这是个人工程作品和方案验证的稳定版本号，不代表养老机构生产认证、医疗器械资质、临床有效性、等保认证或长期 SLA。

## Highlights

- 13 个 Web Agent 工具：8 个只读查询工具与 5 个必须人工二次确认的写操作规划工具。
- 6 个非个人、只读 MCP 工具，以及只索引 `approved` 内容的知识治理边界。
- Spring Boot 4.1 / Java 25 LTS 后端，Vue 3 / Vite 前端，MySQL 9.7 LTS 与 Redis 8.2 Extended。
- Docker 与严格 IDEA + VSCode 两种运行模式，具备健康检查、身份/所有权校验、幂等、审计、限流和敏感信息门禁。
- CI、CodeQL、Gitleaks、Dependency Review、Dependabot 与 OpenSSF Scorecard；非 `scratch` Docker 基础镜像固定到标签和 OCI 摘要。

## Verify before use

```powershell
gh release verify v1.0.0 --repo LeiQingliang/silverpilot
gh release download v1.0.0 --repo LeiQingliang/silverpilot --dir .\silverpilot-v1.0.0
gh attestation verify .\silverpilot-v1.0.0\silverpilot-1.0.0-backend.jar `
  --repo LeiQingliang/silverpilot `
  --signer-workflow LeiQingliang/silverpilot/.github/workflows/release.yml
```

再按 `SHA256SUMS` 独立计算每个下载文件的 SHA-256。快速启动、凭据边界和数据卷说明见源码包中的 `README.md` 与 `docs/DEPLOYMENT.md`。

## Known boundaries

- 演示账号、示例密码和合成种子数据不得直接用于公网生产。
- OWASP Java Dependency-Check 的 NVD 数据更新曾超时，因此没有宣称该扫描通过。
- 未完成真实养老机构、临床、并发容量、灾备、Firefox/Safari、读屏器及独立渗透测试。
- WorkBuddy 企业发布、ima 账号绑定和豆包真实视觉能力仍需要相应外部账号与授权。
