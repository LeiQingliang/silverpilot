# AI Agent 运营与评测手册

## 北极星与护栏

北极星指标不是对话次数，而是“用户目标在正确权限与确认链路内被真实完成的比例”。在没有人工标注任务结果前，`agent_run` 的链路成功率只能作为技术代理指标，不能等同业务完成率。

护栏指标包括：越权拦截率、无工具成功声明、写操作绕过确认、知识来源缺失、紧急健康分流失败、秘密泄露和重复执行。任何关键护栏失败都应阻断发布。

## 当前可观测指标

| 指标 | 当前口径 | 用途 |
| --- | --- | --- |
| Agent Runs | 进入编排且写入 `agent_run` 的次数 | 流量与稳定性基线 |
| 链路成功率 | `COMPLETED` 与 `WAITING_CONFIRMATION` / 全部运行 | 发现模型或工具链故障 |
| 平均延迟 | 请求接收至响应生成的平均毫秒数 | 模型路由与体验优化 |
| 工具成功率 | 成功工具次数 / 工具调用次数 | 发现参数和业务接口问题 |
| 待确认数 | 产生 `WAITING_CONFIRMATION` 的运行数 | 分析确认卡片摩擦 |
| Provider/Modality | 按模型提供方和文本/图文分布 | 成本、质量与路由分析 |

## 运营闭环

1. 每周查看失败类型、P95 延迟（当前需后续补充分位数）和失败最多的工具。
2. 从失败样本中去除个人信息，归纳为评测用例而不是直接保存原始对话。
3. 将改进归类为 Prompt、工具描述、参数校验、知识文档、模型路由或 UI 引导。
4. 在 `evaluation/agent-evaluation-dataset.jsonl` 增补样例并运行结构校验。
5. 通过前后端、知识库和 MCP 门禁后再做真实模型冒烟。
6. 记录变更前后口径一致的结果；没有样本量、时间范围和分母时不报告提升百分比。

## 后续实验设计

- A/B：通用欢迎语 vs. 场景化任务卡，指标为首轮有效意图率和任务完成率。
- A/B：确认卡摘要长度，指标为确认率、取消率、超时率和误操作反馈。
- 路由：DeepSeek 文本 vs. 豆包文本，按任务类型比较正确工具率、延迟与成本。
- 知识：关键词检索基线 vs. 向量/混合检索，按来源命中率与人工事实评分比较。

这些是实验方案；在取得真实样本前不得写成已经产生的业务提升。
