# SilverPilot：业务验证与贡献记录模板

状态：2026-11-11新整理的待执行方案。以下没有真实受试者、客户、实验结果或报价；空项必须用实际证据填写。

## 1. 先验证一个任务

建议首个任务：用户找到符合条件的一项服务，并理解、确认或主动取消预约。优先固定服务数据、任务说明、账户权限及环境，避免同时测试健康判断、图像识别等不同问题。

**需求发现记录**

| 记录项 | 填写要求 |
| --- | --- |
| 使用者、业务负责人、付费决策人 | 区分三类角色；不假定养老机构负责人就是实际使用者 |
| 受访者和授权 | 使用匿名编号，记录角色、日期、用途同意；不收集无关健康或身份资料 |
| 最近一次实际任务 | 当时怎样找服务、核对什么、遇到什么困难、怎样解决 |
| 用户原话与观察 | 区分逐字原话、观察事实和研究者解释 |
| 需求与优先级 | 频率、影响、现有替代方法；保留未选需求及理由 |
| 原型回应 | 对应页面、状态、工具和验收条件 |

**小样本试用建议（计划，不是已完成）**

- 可先邀请5—8位符合目标角色的参与者用于发现问题；该规模仅是探索建议，不能用于宣称统计显著或普遍有效。
- 对比传统页面与Agent的相同任务，交替安排使用顺序，记录学习效应和协助情况。
- 预先定义正确结果：服务、时段、对象等必要字段正确；需要写入时有明确确认；取消任务不得产生写入。
- 公网共享账户不能验证写入。完整任务在已授权测试环境进行，使用合成数据。
- 记录不成功、超时、求助与主动取消，不只保留成功样本。

报告口径：完成率=达到预定义正确结果的任务数/实际执行的有效任务数；同时报告人数、任务数和失败原因。分别报告全部任务耗时与成功任务耗时，防止排除失败样本美化结果。少量样本优先呈现逐例结果、中位数与范围，不写统计显著。

## 2. 形成一条真实运营改进证据

问题编号 → 用户/测试证据 → 根因假设 → 备选方案 → 实际改动 → 相同任务复测 → 结果与剩余问题。

| 项目 | 待填写内容 |
| --- | --- |
| 问题来源 | 真实试用/合成测试/日志分析，明确区分 |
| 原始证据 | 脱敏截图、运行记录或任务观察 |
| 判断与取舍 | 为什么修改Prompt、工具、知识或界面；为什么暂不选其他方案 |
| 版本引用 | 可打开的commit/issue/PR和对应时间 |
| 复测依据 | 任务、数据、环境、样本量和通过标准 |
| 实际结果 | 逐例结果、失败情况、是否可比较 |
| 结论 | 发布、继续修订或回滚；不把口径变更当成效果提升 |

## 3. 模拟售前PoC范围与验收

| 项目 | 当前建议，需与真实客户确认 |
| --- | --- |
| 场景范围 | 服务目录查询和受控预约，不在首轮承诺诊断或多模态效果 |
| 角色 | 使用者、业务负责人、信息化负责人、预算及采购决策人分别确认 |
| 数据 | 字段、更新频率、数据归属、接口及第三方模型处理范围 |
| 成功标准 | 正确任务完成、必要确认、取消无写入、权限与重复执行检查；数值门槛在基线后协商 |
| 交付物 | 演示环境、任务清单、操作说明、验收报告、已知问题和回滚方案 |
| 费用 | 云资源、模型调用、存储、人工复核、集成和维护分别估算 |
| 商业判断 | 是否愿意继续试用、阻碍采购的条件、预算来源；只记录实际反馈 |

成本模型仅作待填测算：月度总成本=托管与存储+实际模型账单+实施与维护人工+人工复核。单位成功任务成本=相同周期可归属成本/真实完成任务数；分母为0时不计算。不要用预留Token额度直接当实际账单。

ROI须等实际基线、试用结果和成本取得后再计算；时间节省应计入人工核验、返工和学习成本。当前没有回本周期或收入承诺。

学校项目期间：按现有简历保留2026.01—2026.08。后续维护与11月新增功能单列，不倒填进学校结项时期。

最值得展示的AI工作样例：一份原任务、一段关键提示、AI初稿的问题、人工选择与纠错、最终结果及验收证据。证明“能判断并完成交付”，不以提示词长度或自动生成代码量作成绩。

## 5. 三分钟演示脚本

- 0:00—0:25：说明使用者、具体任务与待验证痛点；标明演示/合成数据。
- 0:25—1:10：查询服务，展示工具返回真实业务记录，解释模型不直接写库。
- 1:10—1:50：授权测试环境展示待确认、取消及订单核对；公网只读版只解释边界并使用已验证录像。
- 1:50—2:25：展示一条运行记录、失败分类及反馈复测流程，说明运行成功与业务完成不同。
- 2:25—3:00：说明个人、团队、AI贡献，以及尚无真实机构收益、下一步如何试点验证。

录制后标注日期、提交、环境和已验证范围；保留正常语速版本，完整版作为附录。
