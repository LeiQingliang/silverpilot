# 面试证据清单

## 可以直接证明

- 后端不是“调用一次大模型”：它允许模型连续规划并调用 13 个真实工具。
- 写操作不会自动落库：待确认状态、过期、取消、失败、幂等与所有权都有实现和测试。
- UI 展示的是可核验执行轨迹，不展示或伪造模型思维链。
- 图文请求只有在豆包 Vision 配置完整时才会发送；DeepSeek 文本通道会拒绝图片。
- 知识包有审批状态、负责人、版本、复核日期、重复/链接/秘密校验，并与本地检索同源。
- WorkBuddy 可通过标准 MCP 读取公共目录、知识与匿名指标，Skill 可驱动代码/知识升级。
- 运营页的指标来自 `agent_run`，原始 Prompt 和图片没有进入观测表。

## 只能说明“已设计 / 待外部配置”

- 豆包在线视觉效果、成本和稳定性：需要火山方舟 Key 与模型 Endpoint ID 后才能形成实测。
- WorkBuddy 企业 Agent 发布和 ima 原生绑定：需要用户账号、企业权限与 Test Run 结果。
- 机器人和半导体行业方案：目前是数据契约与迁移蓝图，没有客户部署。

## 不能声称

- 真实养老机构客户、签约、收入、回款、留存、复购或转化提升。
- 医疗诊断能力或临床验证。
- 已经生产上线、达到高并发或通过等保。
- 英语可作为工作语言。

## 演示前核验

1. 运行 `scripts/verify-project.ps1`。
2. 启动 MySQL、IDEA 后端和 VSCode 前端。
3. 依次演示读工具、取消写操作、确认写操作、知识检索、指标和 MCP。
4. 演示结束后保留运行 ID、测试输出和不含敏感信息的截图；清理演示订单。
